# Кто платит?

Мини-приложение ВКонтакте для компании: помогает случайным образом выбрать, кто платит за кофе, кто выбирает фильм, кто за рулём и т.п.

## Что умеет

- **Сценарии** — встроенные (кофе, фильм, руль, дежурный, заказ еды, музыка) или свой вопрос.
- **Участники** — можно вводить имена вручную или подтянуть друзей из ВКонтакте.
- **Жеребьёвка** — по кнопке случайно выбирается один человек, результат можно отправить в VK.
- **История** — сохраняются последние выборы (в браузере).

**Взвешенный случайный выбор:** жеребьёвка не равновероятная. Участники, которых уже выбирали раньше (есть в истории), получают пониженный вес (30% от базового), а те, кого ещё ни разу не выпадало — полный шанс. Так со временем выпадают чаще те, кому «не везло», и реже те, кто уже платил за кофе. Всё считается по истории в браузере, без сервера.

## Как запустить локально

```bash
npm install
npm run dev
```

В браузере откроется адрес вида `http://localhost:5173`. Полноценно друзья и шеринг работают внутри VK — после публикации приложения.

## Сборка

```bash
npm run build
```

Собранные файлы лежат в `dist/`. Для публикации в VK залейте содержимое `dist` на хостинг приложения.

## Стек

React, TypeScript, Vite, VKUI, VK Bridge.

## Debug: включение диагностического баннера iframe

В проект добавлен опциональный диагностический баннер, который показывает контекст выполнения приложения внутри iframe (полезно при отладке мини‑приложений ВКонтакте). По умолчанию он выключен.

Как включить:

- На Vercel (build-time): добавьте в Environment Variables одну из пар ключ/значение и выполните redeploy:
  - DEBUG_IFRAME = 1
  - или REACT_APP_DEBUG_IFRAME = 1

- Локально (runtime быстрый тест, не требуется пересборка): в консоли DevTools выполните перед перезагрузкой страницы:
  window.__env__ = { DEBUG_IFRAME: '1' };
  затем обновите страницу — баннер появится только при этом флаге.

Примечание: флаг поддерживает оба имени (DEBUG_IFRAME и REACT_APP_DEBUG_IFRAME) для совместимости с разными CI/сборками.
